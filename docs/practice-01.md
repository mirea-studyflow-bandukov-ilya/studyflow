## Что настроено

Организация получила название, описание и собственный аватар. Контактный адрес установлен по указанию владельца и не опубликован в этом отчёте.

Репозиторий создан публичным с разрешения владельца. В нём находятся README с назначением продукта, запланированными функциями и логотипом, а также .gitignore. Приложение пока не реализовано: первая практика посвящена созданию рабочего пространства.

Доска имеет статусы Todo, In Progress и Done. Её описание и README содержат назначение проекта и ссылки на код и Wiki. Репозиторий studyflow выбран как default repository; проект отображается на вкладке Projects репозитория. Сама доска остаётся приватной и доступна согласно правам GitHub; публичность репозитория не делает доску публичной.

Wiki содержит назначение StudyFlow, описание проблемы и пользователей, план первой версии продукта, порядок организации работы и ссылки на репозиторий и доску. Дополнительные Wiki-упражнения из практики 1.2 здесь не выполнялись.

Для Watching и Participating/@mentions включены уведомления на GitHub и по email. Для Actions включены уведомления только о неудачных запусках. Эти настройки уже действовали и были проверены.

## Отличия платформ

- Organization используется для организации команды и общих ресурсов, Repository — для кода, Project — для доски планирования.
- У GitHub Repository нет отдельного аватара, соответствующего аватару проекта Azure DevOps. Использованы аватар организации и логотип в README.
- Вместо шаблона Azure Agile используется настраиваемая доска GitHub Projects. Идентичность всех полей и процессов Azure DevOps не заявляется.
- Отдельные пользовательские настройки формата даты и времени, как в Azure DevOps, в проверенном интерфейсе GitHub не представлены. Даты интерфейса отображаются с часовым поясом GMT+3; в профиле выбран часовой пояс Moscow (Europe/Moscow, UTC+3) и включён показ местного времени.
- GitHub Wiki на бесплатном плане доступна для публичного репозитория. Поэтому учебный репозиторий создан публичным по явному разрешению владельца.
