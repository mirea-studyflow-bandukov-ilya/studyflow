# StudyFlow

<img src="logo.png" alt="Логотип StudyFlow" width="112" height="112">

Планировщик учебных задач: предметы, сроки сдачи, приоритеты и отслеживание выполнения.

Учебный проект по дисциплине «Программная инженерия». Практические работы выполняются последовательно на GitHub с явным сопоставлением возможностей Azure DevOps и GitHub.

## Цель проекта

Помочь студенту видеть учебные задачи в одном месте и вовремя сдавать работы.

## Планируемые возможности

- Создание предметов и учебных задач.
- Указание срока сдачи и приоритета задачи.
- Изменение статуса: запланировано, в работе, выполнено.
- Поиск и фильтрация задач по предмету и статусу.

Это описание будущего продукта. Реализация приложения в первую практику не входит.
